# Личный сайт — Казим Давидов (проектное управление и консалтинг)

Статический сайт без сборки и зависимостей: чистый HTML, CSS и немного JS.

**Сайт опубликован:** https://davkazimpmo.github.io/kazim-davidov/
Репозиторий: https://github.com/davkazimpmo/kazim-davidov (публичный).
Хостинг — **GitHub Pages**: ветка `main`, папка `/`. Каждый `push` в `main`
публикует изменения автоматически (1–2 минуты).

## Структура

```
site/
├─ index.html                  Главная
├─ about.html                  Обо мне, опыт, навыки, резюме
├─ services.html               Услуги
├─ cases.html                  Кейсы (10 разборов)
├─ blog.html                   Список статей
├─ contacts.html               Контакты и форма
├─ resume.html                 Резюме для печати / PDF (скрыто: не в меню, ссылку даёте вручную)
├─ 404.html                    Страница ошибки
├─ robots.txt                  Для поисковых систем
├─ sitemap.xml                 Карта сайта
├─ .nojekyll                   Отключает обработку Jekyll на GitHub Pages
├─ articles/
│   └─ billions-project-not-working.html
└─ assets/
    ├─ css/style.css
    ├─ js/main.js
    ├─ files/                   PDF-материалы по кейсам
    └─ img/favicon.svg
```

## Как посмотреть локально

Просто откройте `site/index.html` двойным щелчком в браузере — сайт работает без сервера.

Если хотите локальный сервер (опционально), подойдёт любой из вариантов:
- VS Code → расширение **Live Server** → «Open with Live Server».
- Или `python -m http.server 8765` в папке `site` (если установлен Python),
  затем откройте http://127.0.0.1:8765/.

## Публикация на GitHub Pages (бесплатно)

Важно: на бесплатном тарифе GitHub Pages публикуется только из **публичного**
репозитория — файлы сайта будут видны. Для личного сайта, который вы и так
показываете по ссылке, это нормально.

Git устанавливать не обязательно — файлы можно загрузить через браузер.

### Вариант 1. Через сайт GitHub (без установки программ)

1. Зарегистрируйтесь на https://github.com.
2. **New repository**. Имя, например `kazim-davidov`. Репозиторий **публичный**.
3. **Add file → Upload file** и перетащите содержимое папки `site`
   (чтобы `index.html` оказался в корне репозитория).
4. **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch** → ветка `main`,
   папка `/ (root)` → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу
   `https://davkazimpmo.github.io/kazim-davidov/`.

Файл `.nojekyll` в корне отключает обработку Jekyll, чтобы все файлы отдавались
как есть.

### Вариант 2. Командная строка (для повторных правок)

```
cd site
git add -A
git commit -m "Обновление сайта"
git push origin main
```

После `push` GitHub Pages пересобирает сайт автоматически (1–2 минуты).

## Свой домен (опционально)

1. Купите домен (удобно у российских регистраторов: reg.ru, nic.ru).
2. В GitHub: репозиторий → **Settings → Pages → Custom domain** — укажите домен.
3. У регистратора пропишите DNS‑записи по инструкции GitHub (A‑записи на IP
   GitHub Pages или CNAME `www` → `davkazimpmo.github.io`), затем включите
   **Enforce HTTPS**.

## После запуска — чтобы сайт находили

1. Добавьте сайт в **Яндекс.Вебмастер** (webmaster.yandex.ru) и подтвердите права.
2. Добавьте в **Google Search Console** (search.google.com/search-console).
3. Отправьте `sitemap.xml` в обоих сервисах.
4. Разместите ссылку на сайт: в резюме, профиле hh.ru, LinkedIn, Telegram, подписи в письмах.

## Как добавлять статьи

1. Скопируйте любой файл из `articles/` как шаблон.
2. Создайте новый файл, например `articles/moya-statya.html`, поменяйте `<title>`,
   описание и текст.
3. Добавьте карточку статьи в `blog.html` (скопируйте блок `<div class="post">`).
4. Добавьте ссылку в `sitemap.xml`.
5. Закоммитьте и отправьте изменения в `main` — GitHub Pages обновит сайт
   автоматически.
